# v0.2.13 — Logs: project/run selection and compact settings report (stage 1)

Logs is now a read-only project history dashboard, replacing the previous placeholder. The left column lists projects with a real `projects/<name>/experiments/` directory, each project's eligible runs in reverse timestamp order, and the presence of `.log`, `.log.part`, or neither. The right column provides six compact groups: identification, environment, execution, input data, display/appearance, and configuration. Additional saved YAML properties are available on demand. The color accents are local to Logs; the global v0.2.6 theme is unchanged.

Discovery reads project/run directory metadata only; run snapshots (`run.json`, optional `result.json`, optional `gui-settings.json`, and block YAML copies) are read only for the selected run. The `result.json` process status is displayed without reading measurement binding records or following any data paths. Missing, invalid, oversized or linked metadata is handled defensively. JSON is capped at 512 KiB and YAML at 256 KiB. Refresh is on screen entry or manual click, with no background watchers/timers, threads, processes, databases or measurement-data scans.

The **Console Log — next stage** control is intentionally disabled. Viewing the contents of `.log` and `.log.part` is reserved for stage 2. A complete log is **not** equivalent to a successful experiment. Run/stop, PsychoPy, source repositories, the incremental logger, YAML editor, log buffers, Manual, global theme and project data formats have not changed. Windows/DPI integration requires user hardware testing.
