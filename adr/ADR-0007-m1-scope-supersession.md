# ADR-0007 — Scope-first M1: existing demos and config
Status: USER REQUIREMENT, scope accepted 2026-10-10. 
Decision: M1 only existing demos/config/path/source of gaze; design of new experiments deferred. Supersedes order of earlier v0.0.0 roadmap M2 and M3 but preserves them as historic intentions. Rationale: ensure existing authority and OS launch parity before adding novel experiment authoring. Consequences: 7 selectable demo variants, no New Experiment button, no stimulus importer in milestone M1. Review when all 7 demos pass Windows/Linux launch + profile gates.
