# ADR-0009 — Child bridge for adapter demos, no upstream edits
Status: ARCHITECTURE PROPOSAL, must verify compatibility against exact git SHA.
Decision: retain native CLI path for test and time-series; run a thin GUI-owned bridge as a Python subprocess for UX/Text Search/Image Semantic, importing ONLY existing demo_runtime_adapters and original `tobii_pytracker.main`. The adapter's child call passes dynamic enable_eyetracker, voice, raw, log level, loop count and configs. No duplicate dataset/renderer/engine implementation, no modifying upstream or demo original source. All paths/cwd explicit; GUI never imports heavy runtime. Motivated by 3 wrappers hardcoding True/False and lack of OS-neutral Bash. Reject blindly forwarding GUI args to legacy `run_experiment.py` as they are ignored/not recognized. Gate: byte-safe upstream, adapter parity, every mode and label regression.
